# Clipo

軽量なクリップボード履歴アプリ（macOS / Windows）。キーボードだけで全部の操作ができます。

## ダウンロード

[Releases](../../releases/latest) から入手できます。

- **Mac**: `Clipo_*_universal.dmg`（Apple Silicon / Intel 両対応）
- **Windows**: `Clipo_*_x64-setup.exe`

> 署名していないため、初回起動時に警告が出ます。
> Mac は Finder で Clipo を右クリック →「開く」、Windows は SmartScreen の「詳細情報」→「実行」で起動できます。

## 主な機能

- テキスト・リンク・画像・ファイルの履歴。コピー元のアプリ・期間・種類で絞り込める
- Finder / エクスプローラーでコピーしたファイルも、選べば普通のコピー＆ペーストと同じくファイルとして貼れる（パスを文字で貼ることも可）
- 画面下部のパネルにカードを並べて表示（最大3段、ページ式の横スクロール）
- 複数選択してまとめて貼り付け（選んだ順に貼り付け）。⌘V / Ctrl+V のたびに1件ずつ「順番に貼る」も可
- Space で大きく表示、形を変えて貼る（全角⇔半角、改行を消す など）、リンクをブラウザで開く
- よく使うものの「保存」（よく使う順に並ぶ、タグで分類・検索欄の #タグ で絞り込み、短い名前で呼び出し、{日付}・{カーソル} などの差し込み）
- 保存したものの書き出し・読み込み（Mac と Windows のあいだで移せる）
- 日付ごとの区切りと、期間での絞り込み
- 範囲を選んで文字起こし（macOS: Vision / Windows: Windows.Media.Ocr）
- テキストの翻訳（Google 翻訳はキー不要 / DeepL API にも対応）
- 範囲スクショ。Mac 標準のスクショ（⌘⇧4 など）も自動で履歴に入る
- パスワード管理アプリが「記録しない」と指定したコピーは保存しない。記録しないアプリの指定と、記録の一時停止もできる
- ショートカット、履歴の件数、段数、カードの大きさ、背景の透け具合・ぼかしを設定で変更できる

## 初期のショートカット

| 操作 | Mac | Windows |
|---|---|---|
| パネルを開く | ⌘⇧V | Ctrl+Alt+V |
| 範囲を文字起こし | ⌘⇧1 | Ctrl+Shift+1 |
| 範囲スクショ | ⌘⇧2 | （初期はオフ） |

パネルの中では `⌘/`（Windows は `Ctrl+/`）を押すと、すべてのキー操作の一覧が出ます。

## 必要な許可（Mac）

- **アクセシビリティ**: 選んだ履歴を自動で貼り付けるため
- **画面収録**: 文字起こしと範囲スクショのため

## 開発

[Tauri 2](https://tauri.app/) + Rust + Svelte 5 で作っています。

```sh
npm install
npm run tauri dev     # 開発モードで起動
npm run tauri build   # 配布用にビルド
```

### リリースの手順

バージョンを上げた PR を main にマージすると、GitHub Actions がタグ `v<バージョン>` を打ち、
Mac 版と Windows 版をビルドして Release を公開します（両方のビルドが成功したときだけ公開）。

```sh
npm run bump minor        # 0.1.0 → 0.2.0（patch / major / 0.2.0 のような指定も可）
git switch -c release/v0.2.0
git commit -am "Release v0.2.0"
gh pr create --fill       # マージするとリリースされる
```

- バージョンを上げていない PR では、ビルドできるかの確認だけ行います
- README などドキュメントだけの変更では、ビルドも動きません

## データの保存先

- macOS: `~/Library/Application Support/com.clipo.app/`
- Windows: `%APPDATA%\com.clipo.app\`

履歴はこの PC の中だけに保存されます。外部に送るのは、翻訳ボタンを押したときのテキスト（翻訳サービス宛て）だけです。
